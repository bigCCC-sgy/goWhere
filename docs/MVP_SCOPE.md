# 《此刻去哪》第一期游客体验版 MVP 范围

## 1. 一期目标

第一期只验证一个核心闭环：用户无需登录，进入网页后可以选择城市/商圈，输入一句需求或选择场景，拿到 2-3 套基于真实 POI 数据的城市路线方案，并完成分享、反馈、本地收藏。

产品体验优先级高于功能堆叠：首页、推荐结果页、地图路线卡片必须呈现精致、克制、有生活方式感的 iOS 风格，而不是后台系统、普通表单页或商家列表。

## 2. 一期必须实现

- 游客模式：不登录即可完整生成推荐。
- 位置范围：支持全国城市、商圈、地址和地标输入；保留热门位置预设作为快捷入口。
- 定位：仅在用户主动点击后调用浏览器定位；拒绝定位后继续手动输入位置。
- 场景：吃什么、约会去哪、周末去哪、一个人去哪、雨天去哪、朋友聚会。
- 需求输入：支持 1-200 字自然语言，后端做基础校验和风险词拒绝。
- POI：没有 Key 时使用 mock/self-built POI；有高德 Key 时通过 provider 接口切换真实高德 Web 服务。
- 推荐：规则打分筛选候选 POI，返回 2-3 套方案，每套 2-4 个地点。
- AI：没有 Key 时使用 mock AI 文案；有 AI Key 时通过 adapter 调用真实模型。AI 输出必须是 JSON，后端校验地点 ID 全部来自候选 POI 后才返回。
- 前端展示：首页、条件补充区、结果页、协议页、加载态、空状态、定位失败、AI 超时、接口失败。
- 分享：后端生成分享快照和分享码，前端可复制分享链接。
- 反馈：喜欢、不喜欢、太远、太贵、不准、已关门、换一批入库。
- 收藏：游客本地收藏，使用 localStorage 保存路线快照，不做云端收藏。
- 数据库：MySQL 表结构覆盖 area_config、scene_config、poi_cache、recommendation_record、recommendation_plan、feedback、share_snapshot。

## 3. 一期明确不做

- 登录、注册、手机号验证码、邮箱验证码、JWT。
- 云端收藏、历史记录、账号级偏好。
- 管理后台页面、管理员登录、商家入驻后台。
- 团购、优惠券、支付、会员。
- 社区、笔记发布、评论内容流。
- 原生 iOS / Android APP、小程序。
- Redis 接入；POI 和推荐快照先写 MySQL。
- 多城市后台运营配置；一期先通过高德位置解析和周边 POI 搜索覆盖全国常见城市/地标。
- 实时天气 API；第一期仅预留天气权重字段和 adapter 位置。

## 4. 页面清单

- `/` 首页：品牌、位置输入/定位、一句话输入、六大场景、今日灵感卡、协议入口。
- `/generate` 推荐生成/条件补充：场景、预算、同行人、状态标签、生成按钮。
- `/results` 推荐结果：路线方案卡、地图预览、地点时间线、预算/距离/时间、风险提示、导航、分享、反馈、本地收藏。
- `/share/[code]` 分享页：根据分享码读取快照并展示路线卡片。
- `/legal` 协议页：用户协议、隐私政策、AI 生成提示、定位说明。

## 5. 核心后端接口

- `GET /api/config/scenes`：返回六大场景配置。
- `GET /api/config/areas`：返回预设城市/商圈配置。
- `GET /api/location/resolve`：解析手动输入的城市、商圈、地址或地标。
- `POST /api/recommendations/generate`：生成推荐方案，保存推荐记录和方案快照。
- `POST /api/feedback`：保存反馈。
- `POST /api/share`：生成分享快照。
- `GET /api/share/{code}`：读取分享快照。

## 6. 推荐流程

1. 用户输入或定位位置，选择场景、预算、同行人、状态标签和一句话需求。
2. 后端解析需求并做基础合规校验。
3. 场景映射 POI 类型和标签。
4. POI provider 获取候选 POI：优先高德，缺少 Key 或失败时使用 mock/self-built POI。
5. 规则引擎按场景匹配、距离、时间、预算、天气、偏好打分。
6. 选出候选地点并交给 AI provider 生成标题、摘要、理由、路线说明、风险提示。
7. 后端校验 AI 返回的 `poiId` 全部存在于候选 POI，不存在则丢弃或回退 mock 文案。
8. 返回前端并保存推荐记录、方案快照。

## 7. Adapter 设计

- `PoiProvider`：`MockPoiProvider`、`AmapPoiProvider`。
- `AiProvider`：`MockAiProvider`、`HttpAiProvider`。
- `MapProvider`：前端地图预览优先 mock SVG/静态路线卡；有 `NEXT_PUBLIC_AMAP_JS_KEY` 时预留高德 JS API 挂载点。

## 8. 验收标准

- 不登录即可从首页走完整推荐流程。
- 没有外部 API Key 时，本地 mock 版本可完整演示。
- 首页第一眼有高级感和生活方式感，移动端不拥挤、不横向溢出。
- 结果页像城市路线卡，不像商家列表。
- 每次返回 2-3 套方案，每套 2-4 个地点。
- 所有地点来自 mock/self-built POI 或地图 API，AI 不能新增地点。
- 拒绝定位后仍可手动输入城市、商圈、地址或地标并生成推荐。
- 分享、反馈、本地收藏可用。
- AI 超时、接口失败、空结果有明确状态和兜底文案。
- README、`.env.example`、数据库脚本、启动说明齐全。
